# 从零实现 Citrus Code

这套教程面向有 Java 或其他语言基础、Python 经验不多，并且对 Agent 开发有一点了解的读者。
目标是参考 pi 的核心设计，用 Python 逐步实现一个能读写代码、调用工具、保存会话并在终端交互的 coding agent。

教程使用 HTTPX 处理网络请求、Pydantic 处理数据校验，并逐步解释这些库的用途。模型调用、工具执行、
主循环和扩展点由我们自己实现。遇到新的 Python 语法，会结合正在写的代码说明。

## 怎样使用教程

先阅读第零章，理解一次任务怎样在模型与程序之间推进。进入实现章节后，
建议先运行每章的示例，再手写该章标出的核心部分，最后用文末的问题检查自己的理解。
导入、启动入口和重复配置可以复制；消息如何变化、工具何时执行、主循环如何停止，需要能自己解释。

配套代码位于仓库的 [examples/tutorial/](../../examples/tutorial/)。第一章示例独立于完整 Agent 实现，
从仓库环境取得 HTTPX 依赖。后续章节会逐步建立自己的模型层和运行时。

当前 `src/citrus_code/` 是功能较完整的实现，适合在理解相应章节后对照阅读。
配置、CLI 和会话的日常使用说明见 [模型配置](../models.md)、[CLI](../cli.md) 和 [会话](../sessions.md)。

从 [第零章：开始开发 Agent 前，你需要知道什么](00-before-you-start.md) 开始。
已经熟悉基本概念的读者，可以直接进入 [第一章：第一次模型调用](01-first-call.md)。
